## Featured Projects

### 🔐 PKI & Zero-Knowledge Password Vault | *2025* | [Frontend](https://github.com/HakTak/BSEP---2025-Projekat-frontend) · [Backend](https://github.com/HakTak/BSEP---2025-Projekat-backend)
`Java` `Spring Boot` `React` `PostgreSQL` `JWT` `Keycloak` `Auth0` `X.509` `BouncyCastle` `HTTPS/TLS`

A full **Public Key Infrastructure** supporting Root, Intermediate, and End-Entity certificate issuance with complete chain validation, CRL/OCSP revocation, and role-based access control (Admin, CA User, End-Entity). The standout feature is a **zero-knowledge encrypted password manager** where all cryptographic operations happen exclusively client-side via the Web Crypto API, the private key never touches the server. Secrets can be shared across users through per-recipient asymmetric encryption. Secured with reCAPTCHA, 2FA, audit logging, and hardened against XSS and SQL injection. *Group project (3 students).*

---

### 🐇 OnlyBuns, High-Concurrency Social Platform | *2024* | [Frontend](https://github.com/HakTak/onlybuns-social-platform-frontend) · [Backend](https://github.com/HakTak/onlybuns-social-platform-backend)
`Java` `Spring Boot` `Angular` `PostgreSQL` `MongoDB` `RabbitMQ` `WebSockets` `Prometheus` `Grafana` `Docker`

A feature-complete social network built around real distributed systems challenges: **Bloom Filter** for O(1) username collision detection, database-level transaction handling for concurrent likes and follows, and a custom **rate limiter** and **load balancer** implemented from scratch. Real-time group chat via WebSockets, location-based post discovery on interactive maps, and fanout/direct message queues with RabbitMQ. Full observability stack with Prometheus and Grafana. *Group project (3 students).*

---

### 🗺️ Distributed Microservices Tourism Platform | *2024* | [Code](https://github.com/HakTak/soa-projekat)
`Go` `Java` `Docker` `Docker Compose` `PostgreSQL` `MongoDB` `Neo4j` `gRPC` `RabbitMQ` `SAGA` `Grafana`

A multi-language microservices platform (Go + Java) built behind a custom API gateway, with each service fully containerized and isolated via Docker Compose. Implements the **SAGA orchestration pattern** for distributed transaction consistency across three heterogeneous databases: relational (PostgreSQL), document (MongoDB), and graph (Neo4j). Comes with a complete observability stack: distributed tracing, centralized log aggregation, and host and container metrics visualized in Grafana. *Group project (4 students).*

---

### 🎮 RPG Habit Tracker for Android | *2025* | [Code](https://github.com/HakTak/e2-ma-tim47-2025)
`Java` `Android` `Firebase` `Accelerometer Sensor` `WebSockets`

An **offline-first** Android habit tracker built as a full RPG game engine. Daily tasks generate XP and drive level progression, equipment systems, and boss battles, triggered by shaking the phone via the **accelerometer sensor**. Guild missions with real-time messaging, animated loot chests via Lottie, and QR-based friend discovery. Runs on SQLite with Firebase sync so it stays functional with no internet connection. *Group project (2 students).*

---

### 🌅 Desert Oasis, Real-Time 2D OpenGL Scene | *2024* | [Code](https://github.com/HakTak/Pustinja-2D-OpenGL)
`C++` `OpenGL`

An interactive 2D OpenGL desert simulation with a procedural **day/night cycle**: sun and moon traverse opposite arcs as the sky color shifts continuously through dawn, day, dusk, and night, with stars appearing at nightfall. Keyboard-driven interactions include stripe-by-stripe pyramid color manipulation, toggleable oasis elements with a semi-transparent animated fish, time control, and a scripted finale sequence triggered by player input. A deliberate exercise in low-level graphics programming and real-time event-driven systems in C++.
